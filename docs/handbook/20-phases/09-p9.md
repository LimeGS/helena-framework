The last phase, and the one that produces the images that leave the platform.

## Fields

| Field | Required | What it is |
| --- | --- | --- |
| `scroll` | yes | which scroll's plates |
| `out_dir` | yes | where the plate set lands |
| `ordering_of` | | the P8 job whose measured column order this follows |
| `order_path` | | that order as a file, when you already have one |
| `work_dir` | | scratch |

That is the whole surface. P9 composes from what the pipeline already
published; it takes no list of maps, no spacing and no subsampling — those
decisions were made upstream and are read from the order it is given.

## Reading the result

A **plate set**, and the phase verifies it before calling the job a success:

- `PLATE_MANIFEST.json` exists — "P9 exited zero without PLATE_MANIFEST.json"
  is a real failure this phase reports, and the reason the check is here;
- it parses, and it is an object;
- its schema is `campaignx.p9_plate_set.v1`;
- it binds every PNG, the measured P8 order, and the subject.

> **Note** P9's artifact record points at `out_dir`, so that path is bounded to
> the job's own run directory or the store it publishes to. A deployment that
> writes plates somewhere else declares that root; it is not inferred.

## What a plate is not

A plate is a rendering of screening output. It is the most persuasive artefact
this pipeline makes and the one most easily mistaken for a conclusion — it looks
like a photograph of a papyrus, and it is a picture of where a model responded.

> **Trap** The chain that makes a plate trustworthy is the receipt behind it,
> not the plate. A plate shared without its lineage is an image, and an image is
> not evidence.
