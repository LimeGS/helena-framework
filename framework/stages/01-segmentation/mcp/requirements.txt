# imports numpy inside five functions, so the module imports cleanly and fails

# checks this list against the imports actually present rather than trusting it.

# numpy, surface-qc pins scipy -- because two versions of either in one fleet is
# a difference that shows up as an array behaving differently on one host.
#
# Both are imported inside functions, not at the top of the file. That is why
# neither was noticed by reading the imports, and why the check walks the tree.
