# Helena Framework identity kit

Version 1.0

## Brand idea

The mark abstracts a carbonized Herculaneum papyrus as three nested layers opening into a page-like tail:

- **Obsidian** — the carbonized exterior.
- **Papyrus** — the surviving material.
- **Terracotta** — recovered writing and the Herculaneum context.

The silhouette is intentionally bold enough for small digital use while retaining a specific story.

## Logo system

- Use the **horizontal logo** for websites, documentation headers, and repositories.
- Use the **stacked logo** for square or portrait compositions.
- Use the **standalone mark** when the Helena Framework name is already visible.
- Use the **reverse logo** on dark photography or Obsidian backgrounds.
- Use the supplied favicon artwork at 16–32 px rather than reducing the full lockup.

## Clear space and minimum size

- Keep clear space around the mark equal to the width of its innermost Terracotta band.
- Minimum standalone full-color mark: **24 px** high.
- Minimum horizontal logo: **140 px** wide.
- At 16–24 px, use `helena-favicon.svg` or the supplied PNG/ICO exports.

## Color palette

| Color | Hex | RGB | Role |
|---|---|---:|---|
| Obsidian | `#23242B` | 35, 36, 43 | Primary ink, dark background |
| Papyrus | `#E8D7B9` | 232, 215, 185 | Material layer, warm neutral |
| Terracotta | `#C65A36` | 198, 90, 54 | Reveal/accent color |
| Parchment White | `#F7F4ED` | 247, 244, 237 | Primary light background |

For body text on light backgrounds, use Obsidian. Terracotta is an accent, not a long-text color.

## Typography

Primary typeface: **Inter** (SIL Open Font License).

- Wordmark: Inter Regular.
- UI headings: Inter Semibold.
- Body/UI text: Inter Regular.
- Data and code: use the project's established monospace; Inter is not required for code.

The supplied master logo SVGs contain outlined wordmark paths, so the logo does not depend on a local font installation.

## Do

- Preserve the supplied proportions and color order.
- Prefer Parchment White to stark white in editorial layouts.
- Use generous whitespace and restrained Terracotta accents.

## Avoid

- Recoloring individual bands with unrelated colors.
- Adding gradients, shadows, outlines, or texture.
- Stretching, rotating, or separating the bands.
- Placing the color logo on low-contrast photography.
- Using the full wordmark as a favicon.

## File map

- `svg/` — master scalable assets.
- `png/` — transparent and background-backed raster exports.
- `web/` — favicon files, app icons, manifest, and CSS tokens.
- `reference/` — concept board used to extend the approved direction.
